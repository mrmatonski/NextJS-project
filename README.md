# Atelier

Atelier is a polished creative-studio command center built with Next.js. It presents project progress, studio capacity, schedules, activity, and high-level business metrics in a responsive dashboard.

## Features

- Responsive desktop and mobile workspace
- Filterable project portfolio
- Schedule and activity views
- Studio performance metrics
- Accessible navigation and reduced-motion support
- Custom Open Graph sharing artwork

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Validation

```bash
npm run lint
npm test
```

The project uses standard Next.js build output and is ready for Vercel deployment.
